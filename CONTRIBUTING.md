# Contributing to Featherwick

The full rules for issues, branches, commits, code and tests are on their way. Until they land, open an issue before you write any code, and wait for it to be accepted.

## Licensing of contributions

- **Code.** You contribute code under the MIT licence in `LICENSE`, the same licence it is published under. Opening a pull request means you agree to this, and that you have the right to contribute the code.
- **Assets.** Art, sound, music, writing for the game and anything else under a path named in `ASSETS-LICENSE.md` are not accepted without a written agreement first. A pull request that adds or changes those files without one is closed. This keeps every asset under one owner.

## Conduct and security

Follow the [code of conduct](CODE_OF_CONDUCT.md). Report vulnerabilities as [SECURITY.md](SECURITY.md) says, never in a public issue.
